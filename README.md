# Financial Transactions Deep-Dive Analysis & Interactive Dashboard

## Project Overview

This project was developed as part of the ApexPlanet Data Analytics Internship Task 3. The objective was to perform a deep-dive analysis of financial transaction data, define key business KPIs, and build an interactive Power BI dashboard to support data-driven decision-making.

---

## Objectives

* Analyze financial transaction data.
* Define and measure core business KPIs.
* Perform product performance analysis.
* Visualize business insights using Power BI.
* Create an interactive dashboard for stakeholders.

---

## Dataset Information

The dataset contains transaction records with details such as:

* Transaction ID
* Customer ID
* Product Name
* Quantity
* Total Amount
* Payment Method
* Transaction Status
* Transaction Date

---

## Core KPIs

### 1. Total Revenue

Measures the total income generated from all transactions.

### 2. Total Transactions

Measures the total number of transactions processed.

### 3. Average Transaction Value

Measures the average amount spent per transaction.

### 4. Total Quantity Sold

Measures overall product demand.

### 5. Transaction Success Rate

Measures the percentage of successfully completed transactions.

---

## Deep-Dive Analysis

### Product Performance Analysis

The analysis focused on identifying:

* Top products by revenue
* Top products by quantity sold
* Product contribution to total sales
* Product demand trends

### Payment Method Analysis

Analyzed customer preferences across different payment methods.

### Transaction Status Analysis

Evaluated completed, pending, and failed transactions.
